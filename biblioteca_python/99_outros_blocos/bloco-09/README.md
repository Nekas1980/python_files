# Bloco 9 — Exercícios dinâmicos

## Loja de eletrónica

O exercício propõe uma aplicação de compras com:

- catálogo de produtos e preços sem IVA;
- carrinho com vários produtos e quantidades;
- cálculo de IVA a 23%;
- desconto de 2% para compras sem IVA superiores a 500 €;
- desconto de 10% para NIF empresarial, não acumulável com o desconto de 2%;
- oferta de uma noite num hotel do grupo Pestana quando o total final sem IVA ultrapassa 800 €;
- gravação do recibo num ficheiro `.txt`;
- resumo final formatado.

A implementação será mantida como projeto de exercício separado dentro desta pasta.
