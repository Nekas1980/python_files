# Biblioteca Python — Nelson Rijo

Esta pasta é a vista organizada do repositório `python_files`.

## Estrutura

- `01_fundamentos/` — primeiros programas, variáveis, input/output e cálculos.
- `02_condicoes_decisoes/` — `if`, `elif`, `else` e exercícios de decisão.
- `03_ciclos_repeticao/` — `for`, `while`, contadores e repetições.
- `04_listas_colecoes/` — listas, percursos, contagem e manipulação de coleções.
- `05_ficheiros_datas_regex/` — leitura/escrita de ficheiros, datas e expressões regulares.
- `06_scripting_ciberseguranca/` — exercícios UC01481, análise de logs e PyAula.
- `90_enunciados/` — enunciados e materiais de exercícios.
- `91_guia_estudo/` — mapa de estudo e apoio ao VS Code/Git.

## Como usar no VS Code

Na raiz do repositório existe o ficheiro `biblioteca-python.code-workspace`.
Ao abri-lo, o Explorer fica centrado apenas nesta biblioteca, reduzindo o ruído visual dos restantes projetos.

## Regra de organização

Cada exercício deve ficar numa pasta própria com:
1. código `.py`;
2. dados usados pelo exercício, quando aplicável;
3. `README.md` com objetivo, execução e explicação.
