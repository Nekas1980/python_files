# UC01481 — Scripting em Python para Cibersegurança

Área de estudo e exercícios da UC01481.

## Estrutura

- `fundamentos/` — exemplos das matérias dadas em aula:
  - funções;
  - função `main()`;
  - `if __name__ == "__main__"`;
  - tratamento de exceções com `try/except`.
- `exercicio-01/` — análise de ficheiros de log: total de linhas, ERROR e WARNING.
- `exercicio-03/` — ranking de endereços IP em ficheiros de log.

## Objetivo

Ter no GitHub versões simples, comentadas e explicadas para:

1. executar durante a aula;
2. rever a matéria em casa;
3. perceber o significado de cada instrução;
4. aceder ao código a partir de qualquer computador com Git/GitHub.

## Execução

No terminal:

```bash
git clone https://github.com/Nekas1980/python_files.git
cd python_files/uc01481-scripting
```

Se o repositório já existir:

```bash
git pull
```

Depois entra na pasta pretendida e executa o script com:

```bash
python nome_do_ficheiro.py
```

No Windows também pode ser necessário usar:

```powershell
py nome_do_ficheiro.py
```
