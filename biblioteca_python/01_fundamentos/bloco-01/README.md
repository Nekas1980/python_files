# Bloco 1 — Fundamentos de Python

Objetivo: consolidar entrada/saída de dados, variáveis, conversões e operações matemáticas simples.

## Exercícios por ordem

1. Olá, mundo!
2. Pedir o nome e apresentar uma mensagem de boas-vindas.
3. Somar dois números.
4. Converter Celsius para Fahrenheit.
5. Calcular o quadrado de um número.
6. Calcular área e perímetro de um retângulo.
7. Multiplicar dois números.
8. Calcular o IMC.
9. Converter minutos em horas e minutos.
10. Calcular a média de três notas.
11. Converter euros para dólares com uma taxa fixa.
12. Calcular o raio a partir da área de um círculo.
13. Converter quilómetros para milhas.
14. Conversor bidirecional euros ↔ libras.
15. Calculadora de gorjeta.
16. Calculadora de velocidade média.
17. Calcular quantas pizzas são necessárias para uma festa.
