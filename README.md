# Python — Índice de Estudo e Exercícios

Este repositório funciona como **índice central** da formação de Python e como ponto de acesso rápido a partir do VS Code.

## Percurso de aprendizagem

1. **Bloco 1 — Fundamentos**: `print`, `input`, variáveis, tipos de dados, operadores e cálculos simples.
2. **Bloco 2 — Decisões**: `if`, `elif`, `else`, operadores relacionais/lógicos e validação de condições.
3. **Bloco 3 — Ciclo `for`**: `range`, acumulações, padrões, fatorial, tabuadas e números primos.
4. **Bloco 4 — Strings e prática**: métodos de strings, slicing, ciclos, funções e tratamento básico de erros.
5. **Bloco 5 — Listas**: percorrer, transformar, ordenar, contar e separar elementos.
6. **Bloco 6 — Ciclo `while`**: repetição condicionada, jogos de adivinhação, algoritmo de Euclides e conversões.

## Usar no VS Code em qualquer computador

### Primeira vez

```bash
git clone https://github.com/Nekas1980/python_files.git
cd python_files
code .
```

### Antes de começar a trabalhar

```bash
git pull
```

### Depois de alterar ou criar exercícios

```bash
git add .
git commit -m "Atualizar exercícios"
git push
```

Assim, o GitHub passa a ser a fonte central e o VS Code apenas a cópia de trabalho em cada computador.
