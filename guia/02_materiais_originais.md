# Organização dos materiais fornecidos

## Teoria — manter como referência

- `introdução + funções-2.pdf` — material principal de introdução: programação, algoritmos, fluxogramas, variáveis e funções.
- `Resumo Introdução à programação em Python.pdf` — resumo rápido de variáveis, operadores, funções e decisões.
- `atalhos_vscode.pdf` — folha de consulta rápida para VS Code no Windows.

## Exercícios — versão de referência por bloco

### Bloco 1

O ficheiro `exercicios bloco 1.pdf` contém a primeira versão do Bloco 1. Existem versões posteriores com mais exercícios. Para estudo completo, considerar a versão que chega aos 17 exercícios.

### Blocos 1, 2 e 3

`Exercícios fluxogramas e python - Bloco 3pdf.pdf` é o documento mais completo entre os materiais fornecidos para estes blocos: inclui Bloco 1, Bloco 2 e Bloco 3.

### Bloco 4

Não foi fornecido um PDF oficial do Bloco 4 neste conjunto. A organização deste bloco baseia-se apenas nos ficheiros de código já existentes no repositório `bloco-4`. Não foram inventados enunciados para os números em falta.

### Bloco 5

Os ficheiros abaixo contêm o mesmo conjunto de 17 exercícios de listas:

- `Exercícios fluxogramas e python - Ex 5.pdf`
- `Exercícios fluxogramas e python - Ex 7.pdf`

Basta usar um deles como referência; o segundo é duplicado para efeitos de conteúdo.

### Bloco 6

`Exercícios python - while.pdf` contém os seis exercícios do ciclo `while` e deve ser a referência oficial deste bloco.

## Critério de organização

Quando houver vários PDFs com exercícios repetidos, usar a versão mais completa e manter os restantes apenas como arquivo. O código deve ficar no repositório/bloco correspondente e com nomes numerados para aparecer na ordem correta no explorador do VS Code.
