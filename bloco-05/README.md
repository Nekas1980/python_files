# Bloco 5 — Ciclo `for` em listas

Objetivo: percorrer e transformar listas, contar elementos e construir pequenas operações de gestão de dados.

## Exercícios por ordem

1. Percorrer uma lista e imprimir cada elemento numa linha.
2. Percorrer uma lista e imprimir os elementos em linha.
3. Somar todos os números de uma lista.
4. Duplicar os valores de uma lista.
5. Contar quantas vezes um elemento aparece numa lista.
6. Repetir o exercício anterior com `collections.Counter`.
7. Criar um gestor de nomes com menu: adicionar, remover, ordenar, mostrar e sair.
8. Criar uma nova lista apenas com números pares.
9. Converter uma lista de strings para maiúsculas.
10. Calcular a média dos elementos de uma lista.
11. Inverter uma lista com `.reverse()`.
12. Inverter uma lista sem `.reverse()`.
13. Juntar duas listas.
14. Remover números negativos de uma lista.
15. Encontrar o maior elemento sem `max()`.
16. Criar uma lista com o comprimento de cada palavra.
17. Separar números pares e ímpares em duas listas.

## Estrutura recomendada

Usar nomes numerados, por exemplo `01_percorrer_lista.py`, `02_imprimir_em_linha.py`, ..., `17_separar_pares_impares.py`.
