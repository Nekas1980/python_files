# Bloco 5 — Ciclo `for` em listas

Objetivo: percorrer e transformar listas, contar elementos e construir pequenas operações de gestão de dados.

## Exercícios
1. Percorrer uma lista e imprimir cada elemento numa linha.
2. Imprimir os elementos em linha.
3. Somar todos os números de uma lista.
4. Duplicar os valores.
5. Contar ocorrências de um elemento.
6. Contar ocorrências com `collections.Counter`.
7. Gestor de nomes com menu.
8. Criar uma lista apenas com números pares.
9. Converter strings para maiúsculas.
10. Calcular a média de uma lista.
11. Inverter com `.reverse()`.
12. Inverter sem `.reverse()`.
13. Juntar duas listas.
14. Remover números negativos.
15. Encontrar o maior elemento sem `max()`.
16. Criar uma lista com o comprimento de cada palavra.
17. Separar pares e ímpares.

Todos os exercícios estão guardados em ficheiros numerados `01_...py` a `17_...py`.
